# 30 Day Skin Routine PWA – V4 Compact Home

V4 keeps the working V3 routine logic, task persistence, calendar, product library, progress photos, settings and PWA features, while replacing the Home/Today screen with a genuinely compact one-screen layout.

Home design goals:
- No page scrolling on the Today screen
- Minimal, non-bulky layout
- Morning and Night shown side-by-side
- Compact progress line and day indicator
- Works on small Android screens as well as Samsung S23
